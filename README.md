# 🎭 NME (Enemy Mafia)
_New Mafia Extended Mix_

특수 직업이 가득한 온라인 마피아 게임입니다. 4~50명, 직업 53종(시민 포함). 통칭 "애너미(enemy)".

**봇:** 대기실에서 방장이 `🤖 봇 추가`를 누르면 AI 플레이어가 들어와요(한 번에 최대 10명). 사람이 모자랄 때나 혼자 연습할 때 쓰세요. 봇은 사람과 같은 규칙으로 능력·투표·잡담을 하고, **남의 직업을 몰래 보지 않아요.**
`세부설정 → 🤖 봇 난이도`에서 고를 수 있어요.
| 난이도 | 특징 |
|---|---|
| 쉬움 | 증거를 잘 따지지 못해 자주 틀려요. 가끔 행동을 빼먹고, 마피아도 실수로 팀원을 건드려요 |
| 보통 | 경찰 조사 결과와 채팅을 참고해 의심하고, 마피아끼리 밤·투표를 맞춰요. 지목당하면 반박해요 |
| 어려움 | 경찰이 둘 나오면 거짓말을 가려내고, 근거 없이 남을 몰아가는 사람을 의심해요. 마피아는 가짜 경찰로 맞불을 놓아요 |
| 극한 | 증거를 꼼꼼히 따져 표를 모으고, 진짜 경찰은 가짜 경찰을 지적해요. 마피아는 경찰·의사처럼 위협적인 사람을 노리고, 필요하면 동료를 희생해 의심을 피해요 |

봇이 쓰는 정보는 사람과 같아요: 내 직업·내 능력 결과·(접선했다면) 마피아 팀원, 그리고 모두에게 공개된 채팅·사망 공지·득표 수. "누가 누구에게 투표했는지"는 봇도 몰라요. 사람이 채팅으로 한 말(지목, 경찰 주장, 투표 예고 등)도 읽고 반응해요.

**추가 기능**
- **자기 투표:** 세부설정의 "자기 자신에게 투표 허용"(기본 켜짐)으로 켜고 끌 수 있어요. 봇은 자기 자신에게 투표하지 않아요.
- **직업 넣기/빼기·필수 등장·인원수:** 세부설정의 직업 목록에서 마피아·시민을 포함한 모든 직업을 넣고 뺄 수 있어요. ⭐ "필수 등장"(= 최소 1명)을 켜면 팀 최대 인원을 넘더라도 그 직업이 무조건 나오고, 👥 "인원"의 최소·최대로 직업마다 몇 명까지 나올지 정할 수 있어요(커플·거지&부자·광대·파괴자·혁명가는 1팀/1명이 최대). 인원이 모자라면 못 넣을 수 있고, 그땐 게임 시작 때 알려줘요. 마피아를 켜 두면 일반 마피아는 항상 1명 이상 나와요. 마피아·시민을 끄면 그 팀은 특수 직업으로만 채워져요(채울 직업이 없으면 일반 마피아·시민이 대신 들어가요). 거지·부자는 함께 설정돼요.
- **죽으면 직업 공개:** 기본은 **비공개**예요. 방장이 켜면 사망 공지에 직업이 같이 나와요.
- **광대 "섞이기 전 직업" 공개 (2가지):** ① 직업을 뒤섞은 직후 공개 ② 게임이 끝난 뒤 공개 — 각각 따로 켜고 끌 수 있어요(기본 둘 다 꺼짐).
- (이전 설명) **광대가 직업을 섞으면 "섞이기 전 직업" 공개:** 세부설정에서 켜고 끌 수 있어요(기본 꺼짐). 켜면 섞인 직후 모든 사람의 원래 직업이 공지돼요.
- **아침 시간 조절:** 살아 있는 사람은 아침마다 한 번, "10초 줄이기"와 "10초 늘리기" 중 하나를 쓸 수 있어요. 쓰면 모두에게 알려지고, 다음 아침에 초기화돼요.

**설명서·메모:** 방 화면 위쪽 `📖 설명서`에서 규칙, 승리 조건, 직업 도감(이번 방에서 쓰는 직업만 진하게)을 언제든 볼 수 있어요. 게임 중 다른 사람 카드의 `📝`를 누르면 "이 사람은 무슨 직업일까?"를 최대 3개까지 적어 둘 수 있어요. 메모는 내 화면에만 저장되고 새 게임을 시작하면 지워져요.

## 1. 내 컴퓨터에서 해보기
1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더에서 터미널(명령 프롬프트)을 열고 `node server.js` 를 입력합니다.
3. 브라우저에서 `http://localhost:3000` 을 엽니다.
4. 창을 여러 개 열어(시크릿 창 포함) 다른 이름으로 입장하면 혼자서도 테스트할 수 있어요. 최소 4명이 필요합니다.

## 2. 친구들과 하기 (Render에 올리기)
### ① GitHub에 파일 올리기
1. [github.com](https://github.com) 가입 → 오른쪽 위 `+` → **New repository**
2. 이름 `nme`, **Public** 선택 → **Create repository**
3. 화면의 **uploading an existing file** 클릭
4. 이 zip을 먼저 풀고, **안에 있는 파일과 `engine` 폴더 전부**(`server.js`, `bots.js`, `roles.js`, `index.html`, `package.json`, `README.md`, `engine`)를 끌어다 놓습니다.
5. 아래 **Commit changes** 클릭

### ② Render에서 서버 만들기
1. [render.com](https://render.com) 가입(GitHub 계정으로 로그인하면 편해요)
2. **New +** → **Web Service** → 방금 만든 `nme` 저장소 선택
3. 설정
   - Language/Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
   - Region: Singapore (한국에서 가장 가까운 편)
4. **Deploy** → 잠시 뒤 `https://이름.onrender.com` 주소가 생겨요. 이 주소를 친구들에게 보내면 끝!

### 알아두세요 (무료 플랜)
- 15분 동안 접속이 없으면 서버가 잠들고, 다시 열 때 1분쯤 걸려요. 방은 사라집니다.
- Render가 서버를 임의로 재시작할 수 있어요. 그러면 진행 중인 게임이 끊기니, 중요한 판 전에는 미리 열어 두세요.
- 게임하는 동안에는 접속이 계속 있어서 잠들지 않아요.

## 4. 규칙 해석 (원문이 애매해서 정한 부분)
**공통**
- 게임은 1일차 **밤**부터 시작 → 아침(토론) → 투표 → 2일차 밤…
- 팀별 인원수 조정: 마피아·중립·시민 모두 "팀 총 인원"이에요(0이면 자동, 마피아 자동은 인원÷4 내림·최소 1). 예: 마피아 3명 + 일반 마피아 최소 2명 → 일반 마피아 2 + 팀 직업 1. 세 팀 합이 참가 인원과 다르면 시민 팀이 나머지를 맡고, 직업별 최소 인원이 더 많으면 그 최소를 우선해요.
- 승리 조건: **시민 팀** = 마피아 팀과 중립 팀이 모두 사라짐 / **마피아 팀** = 시민 팀+중립 팀 인원이 마피아 팀 인원과 같거나 적어짐 / **중립 팀** = 자신을 제외한 모두가 사라짐 (거지·부자, 혁명가는 각자 추가 조건)
- 투표는 최다 득표자가 한 명일 때만 처형, 동률이면 없음. 정치인은 2표.
- 하루(밤+낮) 동안 아무도 죽지 않은 날이 **6번 연속**이면 더 진행할 수 없다고 보고 무승부로 끝나요.
- 마피아 팀 특수 직업(스파이·마담·암살자·유령·밀고자·사기꾼)은 접선하지 않아도 **처음부터 마피아 팀**이에요(승패 계산에 포함). 접선은 팀원이 누군지 알아내는 수단이라서, 접선 전에는 서로 정체·밤 채팅을 모르고 접선하면 마피아 팀 밤 채팅이 가능해요. (밀고자는 접선해도 밤 채팅에는 참여 불가, 낮 채팅은 모두가 함께)
- 경찰 조사: 일반 "마피아" 직업만 마피아로 나옴(스파이 등은 아님). 은둔자는 마피아로 나옴.
- 마피아가 여럿이면 공격 투표 최다 대상 → 동률이면 무작위, 쏜 사람도 득표한 마피아 중 무작위.

**마피아 팀**
- 마담: 투표한 사람이 유혹 대상(다음 밤 능력 봉인). / 암살자: 2일차 밤부터 매일 랜덤 타겟, 타겟이 그날 밤~낮에 죽으면 접선, 접선 후엔 밤마다 1명을 **상대의 능력을 무시하고** 죽임(의사의 자기 치료, 은둔자·유령의 면역, 군인의 방어를 무시. 다른 사람이 치료해 준 경우는 살아남음). / 유령: 같은 사람에게 이틀 연속 겁을 줄 수 없음. / 사기꾼(구 사기꾼): 조사 결과에 흉내 낸 직업으로 보임, 마피아 전멸 후 접선 상태면 공격 가능. / 밀고자: 투표시간 지목.

- 위조범: 밤에 1명을 골라 마피아면 접선. 접선 뒤에는 투표시간에 1명의 조사 결과를 위조(마피아→마피아 아님, 그 외→마피아). 다음 투표가 끝날 때까지 유지.
- 선동가: 밤에 마피아를 찾아 접선. 접선 뒤에는 기자처럼 1회 속보(다음 날 아침 직업 공개) — 공개할 직업을 마음대로 골라 속일 수 있음.
**시민 팀**
- 과학자: (1회용) 살리는 물약과 죽이는 물약 중 하나만 쓸 수 있고, 하나를 쓰면 나머지는 못 씀.
- 커플은 2명이 함께 배정되며, 마피아가 한 명을 쏘면 다른 한 명이 대신 죽음(의사가 쏜 사람을 살려도 대신 죽는 쪽은 그대로). / 도굴꾼: 1일차 아침에 밤사이 죽은 사람 직업 획득(없으면 시민). / 기자: 밤에 지정 → 다음 날 아침 속보. / 영매: 밤에 죽은 사람과 대화, 성불시킨 사람은 "성불당했습니다" 안내를 받고 말 못함. / 경호원: 밤에 1명을 지킴. 그 사람이 공격(마피아·파괴자·미치광이·물약·암살자)으로 죽으면 모든 플레이어에게 "공격한 사람"이 공개됨(직업은 비공개, 경호원 본인도 비공개, 경호원은 대신 죽지 않음). / 닌자: 그날 밤 닌자↔선택한 사람의 대상이 서로 바뀜. / 사제(구 천사): 1회, 산 사람 1명(자신 포함)에게 "성스러운 가호"를 내림 → 그 사람은 이번 판 첫 공격 1번을 무효로 막음(공격 종류 무관, 의사 치료가 먼저 적용되면 가호는 남음). 누구에게 내렸는지는 사제만 앎. / 테러리스트: 밤에 지목한 사람이 자신을 죽이면 함께 자폭 / 투표로 처형되면 15초 동안 함께 죽을 사람을 고름(안 고르면 아무도 안 죽음).

**중립 팀**
- 거지 & 부자: **한쪽이 죽으면 다른 쪽도 함께 죽어요**(투표·밤 공격·테러 등 어떤 사망이든). 부자·거지는 같이 배정돼요.
- 미치광이: 밤마다 능력을 쓸지 고름(기본 사용 안 함) → 쓰면 자신 포함 랜덤 1명 사망, 처형 투표 1번 방어. / 파괴자: 밤마다 1명 파괴(치료·부활 불가). **횟수 제한: 게임 시작 인원의 1/3(내림, 최소 1번)**. 파괴당하면 모두에게 "파괴당했습니다" 공지(마피아 살해와 구분). 미치광이와는 별개의 직업. / 광대: **2일차 아침** 모든 사람의 직업이 뒤섞이고 광대는 시민 또는 마피아가 됨(그 전에 죽으면 발동 안 함). / 혁명가: 능력을 쓴 사람의 팀이 되며 4일차 낮까지 무관하면 단독 우승. / 거지 & 부자: 설정에서 한 묶음(함께 배정). 부자가 거지를 고르면 만남 → 거지는 말·투표 가능, 투표로 죽을 수 있게 되고 이후 12~17초마다 채팅해야 함(안 치면 "한푼 줍쇼" 자동 전송, 채팅하면 초기화) → 만난 뒤 2일이 지났을 때 둘 다 살아있으면 함께 우승.
- 도박사: 밤마다 "오늘 밤 죽을 사람"을 예측, 실제로 그날 밤 죽으면 적중. **적중 횟수는 세부설정에서 조절**(기본 3번, 1~10) → 달성하면 단독 우승. (처형 사망은 세지 않음)
- 신봉자(구 쌍둥이 신봉자): 시작 때 시민·마피아 팀 중 "주인" 1명이 정해지고 이름·팀을 알려 줌. 주인이 끝까지 살아있고 주인의 팀이 이기면 그 팀과 함께 우승. 혼자 남으면 무승부.
- 생존자: 공격·처형·자폭·능력 무시까지 포함해 딱 2번 죽지 않음. 마피아 팀 또는 시민 팀이 전멸했을 때 살아있으면 우승.
- 형사(시민): 밤마다 1명을 지목하면 그 사람의 직업 후보 3개가 보임(진짜 1개 + 가짜 2개, 순서는 섞임). 후보는 시민·마피아·중립 팀에서 1개씩. 중립 직업이 없는 판이면 시민 1+마피아 2 또는 시민 2+마피아 1. 광대가 섞은 뒤에는 중립 후보에 광대가 나오지 않음.
- 판사(시민, 1회용): 처형 후보가 정해지면 처형의 찬성/반대를 직접 결정함. 최후의 반론이 켜져 있으면 찬반투표 시간에, 꺼져 있으면 처형 직전 짧은 시간(판결이 없으면 그대로 처형)에 쓸 수 있음. 판결하면 판사의 정체가 공개됨.
- 검사 & 변호사(시민, 한 쌍으로 함께 배정): 최후의 반론 뒤 반론 시간과 같은 길이의 발언 시간을 각각 추가로 얻음(검사 → 변호사 순서, 없거나 죽었으면 건너뜀). 찬반투표에서 검사의 찬성은 2표, 변호사의 반대는 2표. 설정창에서는 "검사 & 변호사" 한 줄. 최후의 반론이 꺼져 있으면 나오지 않음.
- 목격자(시민): 밤마다 1명을 지목. 그 사람이 그날 밤 공격받았다면 공격자 후보 3명(진짜 1 + 가짜 2)을 알려 주고, 공격받지 않았다면 그것도 알려 줌.
- 유언집행자(시민): 밤마다 1명을 지목. 그 사람이 그날 밤 죽으면 직업을 알게 되고, 다음 날 아침 약 10초 동안 죽은 사람과 단둘이 대화함(둘에게만 보임).
- 독살자(마피아 팀): 밤에 마피아를 지목하면 접선. 접선한 뒤에는 밤마다 1명에게 독을 걸어 하루 뒤 아침에 죽게 함(2일차 밤에 걸면 3일차 낮에 사망, 그 사이 밤에 의사 등으로 치료받으면 생존). 중독된 사람에게는 알림이 감.
- 내기꾼(중립): 밤마다 1명을 골라 가위바위보(제한 7초, 내지 않은 쪽이 패배: 상대가 안 내면 내기꾼 승, 내기꾼이 안 내면 패). 게임 시작 인원의 5분의 1(올림)명에게 이기면 단독 우승. 이긴 상대에게는 다시 도전 불가, 비기거나 지면 다음 밤에 재도전. 밤이 끝날 때 "가위바위보" 단계가 열리고, 밤 결과(사망 등)는 그 뒤에 처리됨.
- 도둑: 밤에 1명을 골라 그 사람의 밤 능력을 훔침(상대는 그대로) → 다음 밤부터 딱 1번 사용 → 다시 훔칠 수 있음. 한 번 고른 사람은 재선택 불가. 훔칠 수 없는 직업(마피아·사기꾼·암살자·탐정·거지/부자·지원자 등)도 있음. 생존자와 같은 승리 조건.
- 예언가: 첫날 밤 안에 다른 모든 사람의 직업을 예언(입력)한다. 게임이 끝났을 때 절반 이상이 **처음 배정된 직업**과 맞으면 모든 승리(무승부 포함)가 취소되고 예언가가 우승. 입력하지 않으면 우승 불가. 예언가가 있어도 시민 팀의 승리를 막지 않는다.
- **권력자**(부호-정치인)는 아직 정해지지 않아 넣지 않았습니다.

## 🎵 배경음악
- 화면 맨 위 `🔇 음악` 버튼을 누르면 볼륨 패널(스피커 버튼 + 슬라이더 + 퍼센트)이 열려요. 슬라이더를 올리면 바로 켜지고 0%면 꺼져요. (볼륨은 이 기기에 기억돼요, 100%는 예전 '크게'보다 훨씬 커요)
- 음악은 파일이 아니라 브라우저가 직접 만들어 내는 소리라서 저작권·용량 걱정이 없어요.
- 단계마다 분위기가 달라져요: 대기실(포근함) / 밤(어둡고 느림) / 낮(밝은 리듬) / 투표(긴장) / 테러리스트 선택(급박) / 종료(여운). 창을 숨기면 자동으로 멈춰요.

## 🛡 최후의 반론 · 찬반투표
- 투표로 처형 후보(단독 최다 득표)가 정해지면 바로 처형하지 않고 **최후의 반론**(기본 15초)을 해요. 이때는 처형 후보만 채팅할 수 있어요.
- 반론이 끝나면 **찬반투표**(12초, 모두 투표하면 바로 진행)를 해요. 찬성이 반대보다 **많아야** 처형되고, **동점이면 무효**(반대와 같음)예요. 처형 후보 본인은 투표하지 않아요. 정치인은 찬반에서도 2표예요.
- 반대 다수·동점이면 그날 처형은 없고 밤으로 넘어가요. 동률로 후보가 없을 때는 반론 없이 바로 넘어가요.
- 세부설정: `🛡 최후의 반론 사용`(기본 켜짐), `🛡 최후의 반론 시간`(기본 15초, 5~60초). 끄면 예전처럼 바로 처형해요.
- 밤/아침, 사망·처형, 시간 조절, 반론·찬반투표 알림은 채팅에서 **크고 색이 있는 카드**로 보이고, 중요한 알림은 화면 위에 큰 글씨로 잠깐 떠요.

## 내 직업 패널 / 디자인
- 게임 중 화면 위쪽에 "🎭 내 직업" 줄이 항상 보임. 모바일은 눌러서 능력 설명·상태·지금 할 일을 펼치고, 넓은 화면(1200px 이상)에서는 왼쪽에 계속 고정됨.
- 전체 색감·카드·버튼·채팅 디자인을 다듬음(기능은 그대로).

- 경호원(시민): 밤마다 1명을 지킴. 그 사람이 공격받으면 경호원이 대신 공격을 받고, 공격한 사람의 정체가 모두에게 공개됨(직업은 비공개).
- 검사(시민) / 변호사(시민): 이제 따로 나올 수 있음(한쪽만 켜도 됨). 처형 후보의 최후의 반론 시간에 각자 능력을 쓸지 고름(안 고르면 사용 안 함). 쓰면 반론 뒤 추가 발언(검사 → 변호사)을 함. 찬반투표에서 검사는 찬성 2표 / 변호사는 반대 2표가 항상 적용됨(안 써도). 둘 다 안 쓰면 반론 직후 바로 찬반투표. 추가 발언은 누가 하는지 공개하지 않음. 최후의 반론이 꺼져 있으면 둘 다 안 나옴.
- 수호자(시민): 밤에 1명을 지목(기본 1회용, 설정으로 조절). 그날 그 사람은 투표 후보에서 제외됨(투표 시간 능력의 대상도 불가). 단, 그 사람도 투표는 할 수 있음. 제외된 사람은 모두에게 공지됨.
- 악인(마피아 팀): 능력 없는 마피아 팀(시민과 똑같음). 밤마다 1명을 골라 마피아인지 확인하고, 마피아면 접선해서 마피아 팀과 대화 가능. (접선 후에는 밤 행동 없음)
- 관종(중립): 투표로 처형되면 단독 우승.
- 행운아(중립): 시작 시 1~50 중 번호 하나를 받음. 매일 밤 D50(1~50) 주사위를 굴려 같은 수면 단독 우승. 매일 밤 결과가 개인 메시지로 옴.
- 부활 규칙: 부활하면 직업을 잃음. 시민 팀 → 시민, 마피아 팀 → 악인(일반 마피아는 그대로), 중립은 직업 유지.
- 내기꾼 필요 승수: 시작 인원의 5분의 1(올림, 최소 1).

- 투표 기권: 방 설정에서 켜고 끌 수 있음 (기본 꺼짐). 꺼져 있으면 기권 버튼이 없고 봇도 기권하지 않음.
- 능력 사용 횟수: 기자·선동가·성직자·사제·과학자·판사·군인(방어)·광인(처형 방어)·수호자는 1~5회로 조절 (기본 1회). 파괴자 횟수(0=자동)도 조절 가능. 훔친 능력은 항상 1회.

- 방장이 아닌 사람도 방 설정을 볼 수 있음 (게임 중에는 위쪽 ⚙️ 설정 버튼, 방장도 게임 중에는 확인만 가능).
- 수호자는 이제 1회용 (설정으로 늘릴 수 있음).
- 검사/변호사: 추가 발언 시간에 직업을 밝히지 않고 이름만 표시됨.
