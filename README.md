# 🎭 NME (New Mafia Extended Mix)

특수 직업이 가득한 온라인 마피아 게임입니다. 4~50명, 직업 34종(시민 포함). 통칭 "애너미(enemy)".

**봇:** 대기실에서 방장이 `🤖 봇 추가`를 누르면 AI 플레이어가 들어와요(한 번에 최대 10명). 사람이 모자랄 때나 혼자 연습할 때 쓰세요. 봇은 사람과 같은 규칙으로 능력·투표·잡담을 하고, **남의 직업을 몰래 보지 않아요.**
`세부설정 → 🤖 봇 난이도`에서 고를 수 있어요.
| 난이도 | 특징 |
|---|---|
| 쉬움 | 나름 판단은 하지만 자주 틀리고, 가끔 행동을 빼먹어요 |
| 보통 | 마피아끼리 밤·투표를 맞춰요. 경찰 봇은 조사 결과를 알리고, 투표 기록과 채팅으로 의심해요 |
| 어려움 | 누가 누굴 지목했는지 기억하고, 처형·사망으로 공개된 직업에서 추리해요. 마피아 봇이 가짜 경찰 행세도 해요 |
| 극한 | 실수가 거의 없어요. 위협적인 사람(경찰 등)과 우리 팀을 의심한 사람을 노리고, 필요하면 동료를 희생해 의심을 피해요 |

(직업 공개 설정을 끄면 봇은 사망으로 얻는 단서를 쓰지 못해요.)

**추가 기능**
- **자기 투표:** 세부설정의 "자기 자신에게 투표 허용"(기본 켜짐)으로 켜고 끌 수 있어요. 봇은 자기 자신에게 투표하지 않아요.
- **필수 등장:** 세부설정의 직업 목록에서 ⭐ "필수 등장"을 켜면 팀 최대 인원을 넘더라도 그 직업이 무조건 나와요. 인원이 모자라면 못 넣을 수 있고, 그땐 게임 시작 때 알려줘요. 거지·부자는 함께 켜져요.
- **아침 시간 조절:** 살아 있는 사람은 아침마다 한 번, "5초 줄이기"와 "5초 늘리기" 중 하나를 쓸 수 있어요. 쓰면 모두에게 알려지고, 다음 아침에 초기화돼요.

**설명서·메모:** 방 화면 위쪽 `📖 설명서`에서 규칙, 승리 조건, 직업 도감(이번 방에서 쓰는 직업만 진하게)을 언제든 볼 수 있어요. 게임 중 다른 사람 카드의 `📝`를 누르면 "이 사람은 무슨 직업일까?"를 최대 3개까지 적어 둘 수 있어요. 메모는 내 화면에만 저장되고 새 게임을 시작하면 지워져요.

## 1. 내 컴퓨터에서 해보기
1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더에서 터미널(명령 프롬프트)을 열고 `node server.js` 를 입력합니다.
3. 브라우저에서 `http://localhost:3000` 을 엽니다.
4. 창을 여러 개 열어(시크릿 창 포함) 다른 이름으로 입장하면 혼자서도 테스트할 수 있어요. 최소 4명이 필요합니다.

## 2. 친구들과 하기 (Render에 올리기)
### ① GitHub에 파일 올리기
1. [github.com](https://github.com) 가입 → 오른쪽 위 `+` → **New repository**
2. 이름 `nme`, **Public** 선택 → **Create repository**
3. 화면의 **uploading an existing file** 클릭
4. 이 zip을 먼저 풀고, **안에 있는 파일과 `engine` 폴더 전부**(`server.js`, `bots.js`, `roles.js`, `index.html`, `package.json`, `README.md`, `engine`)를 끌어다 놓습니다.
5. 아래 **Commit changes** 클릭

### ② Render에서 서버 만들기
1. [render.com](https://render.com) 가입(GitHub 계정으로 로그인하면 편해요)
2. **New +** → **Web Service** → 방금 만든 `nme` 저장소 선택
3. 설정
   - Language/Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
   - Region: Singapore (한국에서 가장 가까운 편)
4. **Deploy** → 잠시 뒤 `https://이름.onrender.com` 주소가 생겨요. 이 주소를 친구들에게 보내면 끝!

### 알아두세요 (무료 플랜)
- 15분 동안 접속이 없으면 서버가 잠들고, 다시 열 때 1분쯤 걸려요. 방은 사라집니다.
- Render가 서버를 임의로 재시작할 수 있어요. 그러면 진행 중인 게임이 끊기니, 중요한 판 전에는 미리 열어 두세요.
- 게임하는 동안에는 접속이 계속 있어서 잠들지 않아요.

## 3. 파일 설명
| 파일 | 역할 |
|---|---|
| `server.js` | 방/접속/채팅/단계 진행을 처리하는 서버 |

| `index.html` | 화면 |

## 4. 규칙 해석 (원문이 애매해서 정한 부분)
**공통**
- 게임은 1일차 **밤**부터 시작 → 아침(토론) → 투표 → 2일차 밤…
- 마피아 수 = 인원÷4(내림, 최소 1). 방장의 "팀별 특수 직업 최대 인원"은 일반 마피아/시민을 뺀 특수 직업 인원 수입니다.
- 승리 조건: **시민 팀** = 마피아 팀과 중립 팀이 모두 사라짐 / **마피아 팀** = 시민 팀+중립 팀 인원이 마피아 팀 인원과 같거나 적어짐 / **중립 팀** = 자신을 제외한 모두가 사라짐 (거지·부자, 혁명가는 각자 추가 조건)
- 투표는 최다 득표자가 한 명일 때만 처형, 동률이면 없음. 정치인은 2표.
- 접선 전의 마피아 팀 특수 직업(스파이 등)은 마피아와 서로 정체·채팅을 모릅니다. 접선하면 마피아 팀 채팅 가능(밀고자 제외).
- 경찰 조사: 일반 "마피아" 직업만 마피아로 나옴(스파이 등은 아님). 은둔자는 마피아로 나옴.
- 마피아가 여럿이면 공격 투표 최다 대상 → 동률이면 무작위, 쏜 사람도 득표한 마피아 중 무작위.

**마피아 팀**
- 마담: 투표한 사람이 유혹 대상(다음 밤 능력 봉인). / 암살자: 타겟이 그날 밤~낮에 죽으면 접선, 접선 후 능력 무효화. / 도플갱어: 조사 결과에 흉내 낸 직업으로 보임, 마피아 전멸 후 접선 상태면 공격 가능. / 밀고자: 투표시간 지목.

**시민 팀**
- 커플은 2명이 함께 배정되며, 마피아가 한 명을 쏘면 다른 한 명이 대신 죽음(의사가 쏜 사람을 살려도 대신 죽는 쪽은 그대로). / 도굴꾼: 1일차 아침에 밤사이 죽은 사람 직업 획득(없으면 시민). / 기자: 밤에 지정 → 다음 날 아침 속보. / 영매: 밤에 죽은 사람과 대화, 성불시킨 사람은 말 못함. / 경호원: 공격으로 죽을 사람을 대신해 죽음(파괴는 막을 수 없음). / 닌자: 그날 밤 닌자↔선택한 사람의 대상이 서로 바뀜. / 천사: 1회, 소생(산 사람 보호)과 부활 중 하나(시민 팀만 성공). / 테러리스트: 밤에 지목한 사람이 자신을 죽이면 함께 자폭, 처형될 때는 투표시간에 미리 지목한 사람과 자폭.

**중립 팀**
- 미치광이: 밤마다 랜덤 살인, 첫 처형 방어. / 파괴자: 밤마다 1명 파괴(치료·부활 불가). 미치광이와는 별개의 직업. / 광대: 1일차 아침 모든 사람의 직업이 뒤섞이고 광대는 시민 또는 마피아가 됨. / 혁명가: 능력을 쓴 사람의 팀이 되며 4일차 낮까지 무관하면 단독 우승. / 거지·부자: 둘이 함께 배정되고(둘 다 켜야 나옴), 부자가 거지를 고르면 만남 → 2일 뒤 둘 다 살아있으면 우승.
- **권력자**(부호-정치인)는 아직 정해지지 않아 넣지 않았습니다.
